# LUMEN · 粒子手势实验室

单文件 Three.js 交互网页：用摄像头手势（或鼠标/触摸）实时驱动粒子云变形，自带星空、光晕与光迹等氛围效果。摄像头画面仅在浏览器本地处理，不上传。

> 有点小帅的手势控制，做的还不是很完善，和大家一步一步进步

在线演示：<https://imczi.github.io/lumen-particle-gesture/>

## 功能

- 摄像头手势识别，手掌动作实时驱动粒子
- 9 种粒子形态：爱心、花朵、土星、烟花、地球、千里江山、昙花、银河、蝴蝶
- 星空背景、旋转光晕、指尖光迹、过渡光环等多层渲染
- 支持鼠标/触摸作为无摄像头时的回退操作
- 自适应画质：根据帧率动态调整分辨率与特效
- MediaPipe 本地推理，视频数据不出本机

## 快速开始

### 在线使用

直接打开 <https://imczi.github.io/lumen-particle-gesture/>，点击右下角摄像头按钮即可开始手势控制。

### Windows 一键启动

需要本机已安装 Python，然后双击仓库根目录下的：

```
启动LUMEN.cmd
```

脚本会在 `127.0.0.1:8000` 启动 HTTP 服务，并自动打开浏览器。

### 手动启动

在仓库根目录运行本地服务：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8000/index.html>。

> 为什么需要本地服务：浏览器只允许在 `localhost` 或 HTTPS 页面使用摄像头。直接双击打开 HTML 文件时，摄像头可能会被浏览器拦截。

## 手势操作

| 手势 | 效果 |
| --- | --- |
| 张开手掌 | 粒子扩散，光晕与轨道尘埃同步增强 |
| 收拢手掌 | 粒子聚合 |
| 食指伸出并左右摆动 | 旋转模型，指尖游移绘制光迹 |
| 拇指与食指捏合 | 微距透镜放大，中心辉光增强 |
| 手掌左右倾斜 | 粒子翻滚，回正后柔和归位 |
| 手掌前后移动 | 调整视角远近 |
| 保持剪刀手约 0.7 秒 | 切换下一个形态 |
| 保持点赞手势约 0.7 秒 | 返回上一个形态 |

## 技术栈

- Three.js 0.169（ES module，自定义 ShaderMaterial）
- MediaPipe Tasks Vision（HandLandmarker，本地推理）
- WebGL + Canvas 2D 贴图生成

本地无需 npm 安装，页面运行时通过 CDN 加载以上依赖，首次打开需要联网。

## 实现原理

### 总体架构

页面只有一个 `<script type="module">`，运行时从 CDN 加载 Three.js 与 MediaPipe。核心是一个 WebGL 渲染循环：每帧读取手势参数 → 更新 Uniform → 更新粒子位置 → 渲染。手势识别与渲染解耦，手势结果通过一组平滑后的标量（张开度、捏合度、倾斜角、深度等）传给渲染层。

### 粒子生成与形态数据

粒子数量按设备动态选择：移动端 26000，桌面端 44000，宽屏（>1500px）52000。每个形态都是一个纯数学函数，把粒子 `i` 映射到三维坐标，并生成调色板权重、随机种子和缩放因子：

- 爱心、花朵、土星、烟花、地球（大陆斑块 + 陆地判定）、千里江山（脊线地形）、昙花、银河（高斯旋臂）、蝴蝶
- 使用带种子的 `mulberry32` 伪随机数，保证每次加载的粒子分布完全一致

形状数据被缓存，切换形态时只做粒子位置插值，不重新生成数据。

### GPU 渲染

所有点云都用 `THREE.Points` + 自定义 `ShaderMaterial`，并开启 `AdditiveBlending`（加法混合）营造发光效果。顶点着色器负责计算点大小、闪烁、流动、扩散和蝴蝶振翅等位移；片元着色器用圆形渐隐函数绘制柔和光点。

渲染分为多层：

- 星空（900–1800 个，独立闪烁）
- 轨道尘埃（1800–3200 个，绕中心旋转，速度随机正反）
- 光晕层（约为主粒子数的 1/3，更大更柔和）
- 主体粒子
- 光晕 Sprite、聚焦光环、过渡圆环
- 指尖光迹（58 个点连成的 Line + 点阵）

### 手势识别流程

1. `getUserMedia` 获取前置摄像头画面（理想 960×720）
2. MediaPipe HandLandmarker 在 `VIDEO` 模式下输出 21 个手部关键点，优先 GPU 推理，失败自动回退 CPU
3. 隔帧调用 `detectForVideo` 降低 CPU 开销
4. 手部离开画面超过约 210ms 后进入复位状态，所有参数温和回中

### 手势到参数的映射

`updateGesture` 用关键点距离估算四指伸展度、拇指-食指捏合度、手掌跨度与倾斜角，再经过 `smoothstep` 归一化和指数平滑（`damp`）得到连续参数：

- 四指平均伸展度 → 粒子扩散、整体缩放、轨道自旋
- 拇指-食指距离 → 捏合度 → 透镜放大、辉光增强
- 食指单独伸展 → 旋转模型 + 光迹
- 手掌横向倾斜 → 粒子翻滚
- 手掌跨度（远近） → 相机推拉

剪刀手/点赞则用“保持时长”判定（约 0.7 秒），避免误触，并加锁防止连续触发。

### 形态切换与形变动画

切换形态时记录当前坐标为起点，目标形态为终点，每个粒子按各自随机种子错开启动时间，用 `easeInOut` 缓动插值，并叠加一个随粒子种子变化的漩涡偏移，形成“流沙重组”的过渡效果。默认约 1.66 秒，开启“减少动态效果”时缩短为 420ms。

### 渲染循环与自适应画质

`requestAnimationFrame` 主循环每帧计算 delta（上限 50ms），用指数平滑驱动所有手势参数、相机、旋转和缩放。每约 2.2 秒统计一次实际帧率：帧率偏低时降低渲染分辨率、隐藏光晕层，帧率富余时再逐步恢复，尽量保证交互流畅。
